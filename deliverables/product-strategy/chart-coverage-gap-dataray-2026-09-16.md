## 📌 TL;DR

- **现状**：内置 **7 种**图表（表格 · 柱/折/饼/面积/散点 · 透视表），在 9 家可比产品中垫底（≈ Metabase 的 35%、Superset/Quick BI/FineBI 的 <15%）。
- **关键判断**：差距本质**不是"种类数"，而是「类型 × 变体 × 样式」**；Data Insights = 7 类型 × **0 变体** × 3 个样式开关。
- **最关键的一条**：**覆盖率不决定优先级——可替代性（S）与依赖度（D）决定**。横条/环形图/条件格式的覆盖率都是 9/9 家，但因"现有 7 图可凑"而落 P2。
- **该补什么**：P0 仅 **5 项 · 11–18 人日**，且其中 **R-21 多维度分组引擎是 3 项变体（堆叠/百分比堆叠/双轴）的前置**。
- **该停在哪**：边际价值断点 ≈ **图型种类 12 种**（现 7 → 补 5 即达）；变体口径下 ≈14–15。
- **不建议做**：地图（合规前置，触发式）· 桑基 · 甘特 · 长尾六项（词云/子弹/人口金字塔/迷你图/OKR 表/玫瑰图）。

## 四、两轴量化框架（可复算；分值均为**推断**）

**重要性 I = C + F + B**（0–10）　**紧迫度 U = D + K + S**（0–10）

| 因子 | 0 分 | 中 | 满分 |
|---|---|---|---|
| 覆盖率 **C**（0–4） | 1 家做对 = 0.5 | 2–3 家 = 2 | 全覆盖 = 4 |
| 频率 **F**（0–3） | 罕见 | 每周 = 2 | 每天 = 3 |
| 阻断 **B**（0–3） | 有替代 = 0 | 显著降级 = 1.5 | 完全阻断 = 3 |
| 依赖 **D**（0–3） | 不阻塞 | 1–2 需求 = 1.5 | ≥3 需求 = 3 |
| 成本 **K**（反向，0–3） | >15 人日 = 0 | 6–15 = 1 | ≤2 人日 = 3 |
| 替代 **S**（0–3） | 现有 7 图可凑 = 0 | 别扭凑法 = 1.5 | 无替代 = 3 |

**阈值**：I ≥ 8 高 / 4–7.9 中 / <4 低；U 同口径。**P0 = I≥8 且 U≥4**。

> ⚠️ **本框架最重要的性质**：**C 高不等于该做**。横条、环形图、条件格式的 C 都是 4（9/9 家都有），却因 `S=0`（现有 7 图能凑）落 P2。这就是为什么竞析的"必须补 6 项"经框架映射后会变形。

| 口径 | 断点 | 依据 |

## 七、地图为何单列为"触发式"（不能与其他图型并列估成本）

竞析把地图列入"真短板"（9/9 家都有），数析按框架算出 `I≈5.5 / U 低` 落 P2，主理人裁定**单列触发式**。三条非工程前置是决定性的：

1. **ECharts 5 起不内置地图数据**，必须 `echarts.registerMap()` 单独注册 geoJSON；
2. Data Insights 数据集模型**无地理编码语义**（只有 `query_type` / `query_sql` / `columns`）——"省份名 → 几何"这层映射当前不存在；
3. **国内地图有强制性合规要求**：国界、省界、争议地区的呈现必须使用合规标准地图数据源。**这是合规前置，不是工程问题**——覆盖率轴只能衡量"该不该有"，无法衡量"能否合规交付"。

**触发条件**（两条同时成立才启动）：
① 出现真实地理维度诉求（用户主动要求按省/市分析）；
② 接受合规标准地图源 + geoJSON 注册 + 地理维度元数据接入的成本。

## ⚠️ 待确认 / 假设 / Non-goals

**待确认**：
1. **"双轴"的归属冲突**——数析把"双轴"列为 R-21 的验收子项，但又在 P1 单列 **R-58 组合图/双轴**。两者其实是不同机制：**R-21 是"多维度"分组**（series 分组），**R-58 是"多指标"轴**（不同指标上不同轴）。主理人倾向：**双轴归 R-58，R-21 的验收子项仅含堆叠 / 百分比堆叠**。需数析确认或推翻。
2. **count distinct 放 R-48 还是并入 R-06** —— 数析给了 R-48 独立编号，但它本质是"聚合算子"，与 R-06 的"聚合算子集合"是同一类东西。两者会重复实现。
3. 中位数/百分位的**方言支持度**未探针（R-54 开工前必须跑）。
4. 竞析的"内置图表数"能否拿到更硬的口径（当前部分为官方文档枚举值 + 推断映射）。

**假设（显式标注，非实测）**：
- 全部**人日与 I/U 分值为推断估算**，来自数析，未经工程评估。
- 竞析矩阵中"Data Insights 有/缺"为**按类型级去重的推断映射**，非官方口径。
- "补至 12 种覆盖约 80% 日常场景"为行业经验推断（Metabase / Power BI 生态口径）。

**Non-goals（本专题明确不做）**：
- 地图、桑基、甘特、长尾六项（词云/子弹/人口金字塔/迷你图/OKR 表/玫瑰图）。
- 不为"追种类数"而补图——**断点 12 种**，超过后 ROI 断崖。
- 不引入新的图表库（ECharts 已全量引入，能力足够；换库无收益）。
- 不做 3D / 动效类图表。
