## 0. 变更摘要与纠偏

- 需求源原话语义拆解：① 仪表盘延后；② 当期主角 = 单图探索；③ 分享 = 复制地址栏。
- **纠偏（竞析取证）**：火山引擎"智能洞察"= 智能数据洞察 **DataWind**（VeDI 家族），"智能洞察"是能力标签、非独立产品名。DataWind 右上角为「撤销/重做/重置、查询历史、下载、监控告警、查询配置、重命名、图表列表、另存为、保存」——**无分享/复制链接按钮**，其持久化是**命名资源模型**（保存为图表 → 挂仪表盘/公开链接）。
  → **结论**：用户"像火山那样复制地址栏"的类比与事实不符，但**需求本身成立**；对标 URL 即状态的应是 Metabase（`/question#<base64>` + `/public/question/<uuid>`）、Superset（`form_data` + `/explore/p/<key>/` permalink）、Grafana（含时间范围/变量的 URL + `/goto/:uid` 短链）、Looker Studio。
- 形态：单图探索（非看板）；**默认层 URL 即状态**（当期）+ **升级层 token 快照**（延后，复用现有 `/share/:token`）。

## 3. 用户研究洞察（瑞思）

**"复制地址栏"对用户意味着什么**：零决策仪式（不用「点分享 → 命名 → 设密码 → 回传链接」）、零等待（结果已在屏幕上）、可直接贴进 IM。

**四个反噬点（会把这个卖点反噬掉）**
1. **链接过长被 IM 截断** → 对方打开是默认空态（Grafana 因此提供 `/goto/:uid`，Kibana 因此提供 `state:storeInSessionStorage`）。
2. **地址栏是"查询"不是"图"** → 作者以为分享了一张图，实际分享了一条会重跑的查询；口径/结构一变，同一条链接开出不同数字。
3. **短链有生命周期**（Grafana 短链默认 7 天未访问即删）而用户默认以为永久。
4. **地址栏内容会进浏览器历史、IM 记录、企业代理日志**，筛选值一并在内。

**必备项（缺一即退回写 SQL）**：字段可发现（搜索 + 分组 + 别名/注释）· **拖字段即出结果**（无"运行"按钮、无排队）· 筛选与分组是一等公民（时间范围有默认值）· 表格↔图表一键切换 · 每步可回退 · 报错说人话（字段高亮 + 中文提示）· 结果元信息可见（行数/耗时/口径）。
**加分项**：存进图表库 · 导出 · 字段描述 · SQL 兜底通道 · 结果缓存 · URL 分享。
**分界线**：**必备 = 第一次查询能成功且敢信；加分 = 第二次不用从头再来。**

**可用 / 好用判据**

| 维度 | 可用 | 好用 |
|------|------|------|
| 首图步数 | ≤3 步 | ≤2 步 |
| 首图耗时 | ≤60s | ≤15s（命中缓存） |
| 改筛选 → 新结果 | ≤10s | ≤3s（自动重跑） |
| 首次查询无报错完成率 | ≥70% | ≥90% |
| 分享后对方打开一致率 | ≥90% | ≥99% |
| URL 长度 | **<2000 字符（硬约束）** | 超长自动降级短链 |
| 回退能力 | 一键撤销 | 可回到任意历史状态 |

## 4. 竞品对比（竞析）

**该抄火山的**：拖字段入槽位（维度/指标/筛选/TopN/排序/表计算）· 一键 图↔表 切换（含明细表/交叉表）· 顶部 撤销/重做/重置 工具条 · 字段聚合可配（计数/最大/最小/求和/平均/同环比）。
**不该抄火山的**：不要把 DataWind 当"URL 即状态"的对标——它不用复制地址栏。

| 产品 | 图/表切换 | URL 即状态 | 短链固化 | 留痕 | 密码 | 刷新保持 |
|------|-----------|------------|----------|------|------|----------|
| 火山 DataWind | ✅ | ❌ | ✅ 保存为图表/公开链接 | ⚠️ 仅监控 | ❌ | ⚠️ 仅保存后 |
| Metabase | ✅ | ✅ `#base64` | ✅ `/public/uuid` | ✅ 可 revoke | ❌ | ✅ |
| Superset | ✅ | ✅ `form_data` | ✅ `/explore/p/key` | ✅ | ⚠️ 靠登录 | ✅ |
| Tableau | ✅ | ⚠️ 仅传筛选/参数 | ✅ 视图唯一链 | ✅ | ✅ 站点权限 | ✅ |
| Quick BI | ✅ | ⚠️ pageId/ticket | ✅ 公开/私密/免登票据 | ✅ | ✅ 私密需权限 | ✅ |
| Grafana | ✅ | ✅ 含时间范围/变量 | ✅ 短链 + snapshot | ✅ | ⚠️ 匿名默认关 | ✅ |
| Looker Studio | ✅ | ✅ 含筛选/日期 | ⚠️ 指向报告非状态 | ✅ | ✅ 需登录 | ✅ |

**URL 编码方案对照（长度与演进）**：跨栈兼容线 **2000 字符**（de facto）；RFC7230/9110 建议 ≥8000 octets；nginx ≈4096；Apache 8190；IM/CDN 会截断。Metabase `#hash` 链接常达数千字符，IM 发送易被截断。
**能力差**：URL 即状态**无法撤销 / 加密码 / 统计访问**（链接即数据），且数据为**实时**；token 快照三者皆可且快照即真相。
**裁定 = 分级共存**：默认层（当期）URL 即状态，零后端存储零迁移；升级层（延后）token 固化，服务撤销/过期/密码/留痕/跨结构稳定渲染。这正是 Metabase（`#hash` + `/public`）与 Superset（`form_data` + permalink）已验证的组合范式。

## 7. 关键流程 / UI 结构 + 契约裁定

**布局**：字段面板 → 拖拽槽（维度 / 指标 / 筛选 / TopN / 排序）→ 结果区（图 / 表）→ 顶部工具条（撤销 / 重做 / 重置 / 复制链接）。
**URL 同步时机点**：① 任一槽位变更（debounce 300ms 写 `?state=`）；② 图↔表切换；③ 撤销/重做/重置后；④ 初次加载从 `?state=` 还原（无则默认态 + 默认时间范围）。

**裁定 1（页面形态）**：**改造现有 `/chart-builder`，不新开路由**。理由：1694 行可渐进重构（抽出 state 编解码 hook 与工具条组件）；`?edit=` 保留为"加载既有图表进编辑器"的兼容入口，与 `?state=` 互斥（同存时 `?edit=` 优先并提示）；新开路由会造成双入口双维护。
**裁定 2（保存为图表）**：**保留**"另存为图表 → `/charts` → `/share/:token`"链路。理由：`/charts`、`/shares`、`/share/:token` 全依赖它；URL 即状态是临时分享，图表是可复用资产——二者正是默认层/升级层的关系。
**裁定 3（分享动作）**：地址栏与显式「复制链接」**两者都要**。地址栏是唯一真相源；「复制链接」= 读取当前地址栏写剪贴板的便捷动作（+埋点），**不引入第二套状态**。
**裁定 4（撤销/重做/重置）**：**本期做**（R-32），因瑞思将"每步可回退"列为必备项。
**裁定 5（URL 状态契约）**
- **编码**：`lz-string` 压缩 + base64url，`?state=<payload>`，payload 含 `v` 版本字段。
- **序列化对象**：以 `/chart-builder` 前端 camelCase `QueryConfig` 为准，加载时经**既有适配层**转后端 `QuerySpec`。理由：URL 是 UI 状态快照，绑定后端结构会让前端改版即断链；适配层已存在，复用成本最低。
- **长度上限**：>2000 字符 = **显式报错**并引导"另存为图表"，**禁止静默降级/静默截断**。
- **版本演进与容错**：`v` 不匹配 → 尝试迁移；失败 → 降级为"部分还原 + 高亮缺失项"，不整页报错。字段/数据集已删（U-03）同策略。
