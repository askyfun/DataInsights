# 功能指南（Features）

> 最后更新：2026-10-17
> 面向使用者：每个功能按「**是什么** / **为什么做它** / **怎么用** / **边界与已知限制**」四段说明。
> 想了解背后的查询链路、契约模型与 SQL 生成，见开发者指南的 [chart-query-design.md](../developer-guide/chart-query-design.md)。

## 数据源管理

- **是什么**：一个可连的数据库连接配置。支持 PostgreSQL / MySQL / ClickHouse / StarRocks 四种方言，含连接测试与表 / 列 / 表数据浏览。
- **为什么做它**：直连多种方言、**零建模工具依赖** —— 不要求先建 dbt 工程或外部中间件，连上就能用。
- **怎么用**：新建 → 选方言 → 填连接信息 → 测试连接 → 保存；之后可浏览目标库的表 / 列与表数据。
- **边界与已知限制**：连接能力因方言而异；同一种数据库在不同版本上的高级能力（如 GROUPING SETS、窗口函数、百分位）支持参差，凡是受方言能力门控的功能都不做过度声称。

## 数据集管理

- **是什么**：在数据源之上定义"取哪份数据"—— 两种模式：直接选表的**物理表**，或写一段查询 SQL 的**自定义 SQL**。每一列可定义类型与角色（维度 / 指标）。
- **为什么做它**：把"写 SQL"这件事**开放给非技术人**的落点：一次定义好数据集，之后只靠拖拽复用。
- **怎么用**：新建向导 → 选模式（表 / SQL）→ 确认列定义（类型 / 角色）→ 预览。
- **边界与已知限制**：列的**稳定 id**（如 `0000i529`）是配置引用的键，改列名不会切断已存图表；预览与取数受目标库能力约束。

## 本地文件上传（即时分析）

- **是什么**：把本地 `.csv` / `.xlsx` 拖进来，自动解析、**推断列类型**、建好数据集，直接进入拖拽建图。**零配置**——不需要先建数据源、不需要设环境变量、不需要重启。
- **为什么做它**：这是「进不来」的入口墙。用本地表格的人不会先部署一个数据库；而在看到第一张图之前的所有步骤，都是纯流失。上传是「我自己的数据」最短的那条路。
- **怎么用**：数据集页「上传文件」，或空态直接把文件拖进虚线框 → 上传并解析 → 弹窗里复核推断出的列类型 / 维度指标角色 → 「开始分析」。要换文件时在数据集上「替换文件」，**展示名未变的列会保留原列 id**（已有图表不断链）。
- **边界与已知限制**：
  - **上限**：单文件 ≤ 50MB、≤ 1,000,000 行、≤ 1,000 列。三项各自独立校验，超限时提示指明是哪一项。
  - **类型推断只认同形态**：某一列出现脏值（`1,234` 千分位、`50%`、`$1.50`、`(100)` 会计负数等）时**整列退回字符串**，不做「尽力解析」——把 `1,234` 猜成 `1234` 是在替你编数据，而且你看不出来。前导零（`007`）与科学计数法（`1e5`）会被识别为数值，这是有意的：它们是合法数值文本。上传后可在复核弹窗里手动改。
  - **落库位置默认是应用自身的数据库**（详见[配置项字典](configuration.md)）。这条内部存储数据源不出现在列表、也不能被普通数据集引用，**不要删它**——已上传的数据集按 id 引用着它。
  - 替换是**整表替换**，不支持增量追加；单文件上传，不支持多文件批量。

## 内置示例数据集

- **是什么**：首次部署即可一键加载的电商示例数据（「示例：电商订单」+「示例：商品目录」），列类型与维度 / 指标角色已预置。
- **为什么做它**：自部署评估者的第一小时不该被「先搞一台有表的数据库」卡住；装完即有数据可玩，才能在看产品价值之前不流失。
- **怎么用**：数据集列表为空时页面顶部出现引导条 →「加载示例数据集」自动建好数据集并直达图表页；不感兴趣点「忽略」（选择持久化，重启后不再出现）。示例数据集在列表中带「示例」标识，列表顶部可「移除示例数据」整体清理。
- **边界与已知限制**：示例数据落库在应用自身的 PostgreSQL（表名 `di_sample_*`，由迁移灌数），因此示例数据源只适用于 PostgreSQL 部署，且在数据源列表中始终隐藏、不能用于创建新数据集；示例数据源连接固定使用 `sslmode=disable`，托管数据库若强制 SSL 会导致示例取数失败。移除只软删数据集 / 数据源（连带其图表），种子表保留，可再次加载；不做多主题示例库与示例仪表盘模板。

## 拖拽式图表构建（核心）

- **是什么**：把字段拖进维度 / 指标**槽位**即出图，支持过滤、排序与 13 种图型。
- **为什么做它**：**任一改动即时出图** —— 拖拽与结果之间没有"先配置再 Run"的割裂，这是本产品在交互体验上的主线优势。
- **怎么用**：字段库 → 拖入维度 / 指标槽位 → 预览 → 加过滤 / 排序 → 保存或分享。
- **边界与已知限制**：不同图型对槽位的数量与类型有约束，切换图型时会按图型定义补齐最小槽位；受方言能力门控的图型只在支持的数据源上可用（见各图型说明）。

### 13 种图型一览

表格 · 透视表 · KPI 卡 · 柱状图 · 折线图 · 面积图 · 组合图（双轴） · 饼图 · 漏斗图 · 雷达图 · 散点图 · 直方图 · 箱线图。

此外还有柱状横向条形、饼图环形等变体。

### 图表配置项

- **饼图**：显示百分比、其他标签（长尾合并阈值的能力保留但**当前未接线**）。
- **表格**：每页行数、是否显示分页、是否显示总数。
- **合计行**（表格）：右栏「图表配置 → 合计行」打开后，表尾追加一行合计，标签固定为「合计」。
  数值由后端在**过滤后的完整数据集**上重算（不是当前页明细相加），因此翻页时合计不变、
  且 AVG / 去重计数不会被算成"平均数的平均数"。无维度时主查询本身就是一行全表聚合，
  不再重复给合计。配置随图表持久化，分享页与仪表盘同口径渲染。
- **占比显示**（表格）：字段属性里打开「显示占比」，该指标列按 `值 / 全集合计` 显示为百分数。
  分母是**过滤后全部数据**的合计（后端重算），不是当前页相加，所以同一行在任意一页的占比都一致；
  拿不到分母时该列留空，不会退化成"用本页合计算"的错数。开关即格式串的 `%` 后缀
  （`0,0.00%` = 两位小数的占比），随图表持久化，分享页与仪表盘同口径。
- **样式开关**：配色、平滑、堆叠、方向（横向 / 纵向）、环形、表格行密度等，按图型提供。
- **Top N**（柱状 / 折线 / 面积 / 饼图）：右栏「Top N」卡片按所选指标对维度值取前 N
  （可切换从大到小 / 从小到大），排名由数据库完成排序截断（`ORDER BY 指标 LIMIT N`），
  不是取回全量再在页面上切——所以其他图元看到的就只有前 N。仅在恰好一个维度时开放
  （多系列拆分下「前 N」无从对应）。配置随图表持久化，分享页与仪表盘同样生效。
- **参考线**（柱状 / 折线 / 面积图）：右栏「参考线」卡片可叠加常量线、均值线、中位数线，
  按指标逐条挂载并可命名；均值 / 中位数在**当前查询返回的数据**上计算（受筛选与行数限制影响）。
  配置随图表持久化，分享页与仪表盘同口径渲染。
- **同环比**（柱状 / 折线 / 面积 / 表格）：右栏「同环比」卡片可选环比（上一等长周期）或
  同比（前一年），按当前唯一维度（日期）对齐，追加 `(上期)` 与 `(增长率%)` 两条系列 / 两列。
  基线是把当前日期筛选窗口**整体平移**后重新取数（不是按行错位），所以缺数桶得空值而非借用邻行。
  需在该日期维度上配有上下界的筛选（日期芯片 / 固定区间均可）。配置随图表持久化，
  分享页与仪表盘同样生效（无论窗口由前端展开还是后端按意图现算，基线都跟着已解析的区间走）。

## 日期筛选

- **是什么**：对齐"日期筛选"心智的一套日期条件，含五种模式（动态日期 / 固定日期 / 高级 / 特殊值 / 单个日期）、粒度（年-月-日 / 年-月 / 年-周）与快捷选项。
- **为什么做它**：让**动态日期在所有路径上都成立** —— 图表查询页、分享页、仪表盘盘级筛选都按同一个"意图"各自解析。
- **怎么用**：把日期字段拖入「筛选」区 → 在日期筛选弹窗里选模式与粒度 → 确认。
- **边界与已知限制**：区间口径统一以"昨天"为数据上界（`本周` = 本周首日~昨天、`本月` = 本月 1 日~昨天），这是"T+1 落数"的默认假设，要含今天需用"自定义 + 包含今天"显式打开。另有**三项能力暂缺**：工作日（排除周末）、最近有数 N 天、跨筛选器跳转。
- **意图 ≠ 快照**：条件里存的是"意图"（如 `最近 7 天`），在真正取数时才解析成区间。

## 分享

- **是什么**：分享能力现在只有一种形态——**查询记录的短码直链**（见下一节）。
- **为什么做它**：「快照即真相」比「一条长期有效的口令链接」更符合分析场景：分享出去的内容不会随数据刷新而变。
- **怎么用**：执行一次查询 → 复制地址栏里的 `?q=<短码>` → 发送链接。
- **边界与已知限制**：早期的**图表口令分享**（免登录只读视图、密码 + 过期）已整体下线（issue #112），
  对应的分享清单 / 吊销入口不再存在；历史分享链接一律失效。链接本身是匿名的，访问边界请靠网络层（内网 / 网关）控制。

## 查询记录（「地址栏即分享」）

- **是什么**：每次成功查询落库（内容 hash 去重）并生成短码直链（`?q=<短码>`），复制地址栏即分享。
- **为什么做它**：**「快照即真相」** —— 分享出去的是一条**不可变快照**，别人再查不会改变已分享链接的内容与有效期。
- **怎么用**：在查询页执行一次查询即自动落库；复制地址栏的 `?q=` 直链即可分享，打开即还原当时的配置。
- **边界与已知限制**：记录 90 天后过期，但**过期不阻断读取**（直链保活，条件 100% 还原，过期与否只看返回的 `expired` 字段）；记录体积上限 **32KB**。

## 仪表盘多页面

- **是什么**：一个仪表盘内含多个**页面**（sheet/标签页），底部标签条切换；每页有自己独立的 12 列布局与筛选器。
- **为什么做它**：一张看板常常要分主题分屏（总览 / 明细 / 趋势），多页面让同一个盘承接多个视图，而不必拆成多个盘。
- **怎么用**：编辑器底部标签条 —— 「添加页面」新增；双击标签就地改名，或用标签上的 ⋮ 菜单改名 / **复制页面**（页与块一并复制）/ 删除；拖标签左侧把手可调整顺序。盘级筛选器可在块上把**作用范围**设为「本页」或「全部页面」。
- **边界与已知限制**：① 盘至少保留一页（只剩一页时删除项禁用）；② 切换页面**不重置**筛选器取值，取值按筛选器在会话内保持；③ 页面数与每页组件数**没有上限**（layout JSON 随之膨胀）；④ 复制页面会重新生成块 id，因此副本与源页此后各改各的。

## 仪表盘 v1

- **是什么**：12 列栅格上的多图视图，含图表块、文本块与**盘级筛选器**；打开时**一次请求多块联动取数**（只取当前页）。
- **为什么做它**：从"一张图"到"一个视图" —— 把若干相关图表与一组公共筛选器组合成一个可交付的看板。
- **怎么用**：新建仪表盘 → 摆放图表块 / 文本块 / 盘级筛选器 → 保存；盘级筛选器按（数据集, 列）绑定，改变取值即联动所有相关图表。
- **边界与已知限制**：盘级筛选有两处已知边界 —— ① 盘级筛选每个筛选器每次查询最多产生**一条**合并条件，因此"包含空日期"（区间 OR IS NULL）在仪表盘侧表达不出来；② **未保存的图表块**走本地取数、不带盘级筛选——新增的筛选器只作用到**已保存**的图表块（筛选器本身新增/改动后**立即生效**，无需先保存仪表盘）。

## 查询容器

- **是什么**：一块把多个盘级筛选器**归拢在一起**的容器控件（对标火山「查询容器」），支持**置顶**到仪表盘顶部。它只做视觉分组，不改变任何筛选器的取数口径。
- **为什么做它**：盘级筛选器多了以后散落在栅格各处、不好找；用一个带标题的容器把它们收成一排，并把常用的一组**置顶**，进入仪表盘就能直接操作。
- **怎么用**：编辑器工具条「添加容器」→ 出现一块容器（默认可改标题）→ 在容器上的「加入筛选器」下拉里把本页已有的筛选器归入它（成员旁的 × 可移出）→ 点容器右上角图钉 **置顶**，容器即从栅格移到盘顶控件条（再点取消置顶回到原位）。删除容器会把它名下的筛选器退回独立块，不会连带删掉。
- **边界与已知限制**：① 容器与其成员**同页**（成员靠 `containerId` 指向容器，与页面归属 `pageId` 同为扁平引用，不嵌套）；② 置顶只是渲染分流，容器仍保留自己的栅格位置，取消置顶即回到原处；③ 成员筛选器的「未落库需保存才生效」等盘级筛选边界照旧适用。

## 皮肤（主题）

- **是什么**：全站浅色 / 深色 / 跟随系统三档主题，含页面骨架、表格、弹窗与图表画布。
- **为什么做它**：分析人员长时间盯屏，深色在低光环境更护眼；跟随系统让深浅色随操作系统自动切换，无需手动。
- **怎么用**：顶栏右侧（语言切换旁）的主题下拉选择「浅色 / 深色 / 跟随系统」；选择会记住，刷新后保留；选「跟随系统」时，切换操作系统的深浅色设置，页面会实时跟随。
- **边界与已知限制**：偏好只存在本机浏览器（localStorage），换设备/清缓存后回到默认「跟随系统」。

## 账号与登录（R-82）

- **是什么**：平台有了账号体系。首个注册账号自动成为**系统管理员**，之后注册关闭；登录后签发有效期 24 小时的**会话 token**。
- **为什么做它**：为"谁能建/看哪些资源"提供身份基础（Phase C 的资源隔离、权限治理的前置）。
- **怎么用**：左侧导航「账号设置」→ 首次进入切到「注册」填用户名/口令即建管理员；此后用「登录」。会话 token 只存浏览器内存，**刷新页面需重新登录**（人类短期令牌的刻意存储策略）。
- **边界与已知限制**：① 会话无自动续期（refresh），24h 到点重新登录；② 现阶段资源端点尚未强制鉴权（渐进启用），登录主要用于管理与取 PAT。

## 个人访问令牌（PAT，面向 AI 工具）

- **是什么**：在「账号设置 → 个人访问令牌」自助创建的**长期令牌**，默认 90 天，可勾选"长期/不过期"（会提示风险）。明文**只在创建时显示一次**，之后列表里只剩可识别前缀（`di_pat_xxxxxx…`）。
- **为什么做它**：让 AI 工具 / MCP server / CLI / 脚本能像人一样访问平台 —— 平台要能被机器驱动，不只面向人。
- **怎么用**：登录后在账号设置创建 PAT，配进工具即可。最小示例：
  ```bash
  # 列出图表
  curl -s -H "Authorization: Bearer di_pat_你的令牌" http://<host>:23352/api/charts
  ```
  任意支持自定义 `Authorization` 头的 MCP 客户端同理填 `Bearer di_pat_…`。可随时在列表点删除按钮**撤销**，撤销**即时生效**（不留缓存窗口）。
- **边界与已知限制**：① PAT **不能**调用管理类端点（创建/列出/撤销 PAT 必须用人类会话），防止机器令牌自我提权；② 首期 PAT 为全量范围，只读/读写细分留给后续（R-84）。
